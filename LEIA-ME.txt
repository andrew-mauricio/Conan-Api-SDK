Conan-Api SDK — escrever plugins para Conan Exiles
===================================================

Este arquivo e' TRADUCAO. O documento principal e' o README.txt, em ingles, e
e' ele que fica atualizado primeiro.

O QUE VOCE PRECISA
------------------
  Um compilador C++ que gere DLL de 64 bits para Windows. Mais nada.
  Nao ha biblioteca para linkar, nem codigo nosso para compilar junto.

  Visual Studio 2017, 2019 ou 2022  (v141, v142, v143 — qualquer um)
     Projeto: Biblioteca de Vinculo Dinamico (DLL)
     Plataforma: x64            <- obrigatorio; DLL de 32 bits nao carrega
     C/C++ > Geral > Diretorios de Inclusao Adicionais: a pasta include daqui
     C/C++ > Geracao de Codigo > Biblioteca de Runtime: /MT   (NAO /MD)

  ou mingw-w64 (Linux, macOS ou Windows)
     x86_64-w64-mingw32-g++ -std=c++17 -O2 -shared \
         -I include -o MeuPlugin.dll MeuPlugin.cpp \
         -static-libgcc -static-libstdc++

  POR QUE /MT E -static-*: sem isso a sua DLL depende do runtime do compilador
  estar instalado na maquina. O servidor roda sob Wine, num conteiner onde ele
  pode nao existir — e o sintoma e' LoadLibrary falhando com um codigo generico
  que nao explica nada.

  POR QUE QUALQUER COMPILADOR SERVE: o que atravessa a fronteira e' uma struct
  de ponteiros de funcao em C puro. Nao ha std::string nem vtable nossa
  cruzando, entao nao ha o inferno de ABI que obriga outras APIs a exigir o
  mesmo compilador delas.

O QUE VEM AQUI
--------------
  include/Conan/ConanPluginApi.h    a tabela da API — e' so isto que voce inclui
  include/Conan/ConanPermission.h   consultar VIP e permissoes (opcional)
  Exemplos/                         exemplos com fonte, para copiar
  Docs/PARA-DESENVOLVEDORES.pt.md   o guia completo
  Docs/EVENTOS.pt.md                quais eventos do jogo existem
  PUBLICAR-PLUGIN.pt.md             o que a gente pede de um plugin publicado

COMECE ASSIM
------------
  cp -r Exemplos/ExemploOla MeuPlugin
  cd MeuPlugin && ./compilar.sh

  Depois copie a PASTA MeuPlugin (com a .dll dentro) para
  Conan-Api/Plugins/ do servidor e reinicie.

VERSOES: O QUE PRECISA BATER
----------------------------
  Seu compilador NAO precisa ser o mesmo que o nosso.
  Sua DLL precisa ser x64 e nao depender de runtime externo (/MT).

  No seu PluginInfo.json, declare de qual versao da tabela voce precisa. Se o
  servidor tiver uma API mais velha, o carregador RECUSA seu plugin e diz qual
  versao falta — em vez de deixar rodar lendo estrutura que mudou de tamanho.

  E confira sempre, na primeira linha do seu ConanPluginCarregar:

      if (!api || api->tamanho < sizeof(ConanApiTabela)) return;

QUANDO O JOGO ATUALIZAR
-----------------------
  Quem precisa ser regerada e' a API, nao o seu plugin: voce fala com a tabela,
  e a tabela nao muda de forma. A excecao e' plugin que usa offset cru do jogo
  (como o layout do chat) — esse precisa de conferencia.

Para RODAR um servidor, baixe o outro pacote:
github.com/andrew-mauricio/Conan-Api
